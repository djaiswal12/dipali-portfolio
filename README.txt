DIPALI PATEL — PORTFOLIO (offline copy)
=======================================

HOW TO OPEN
-----------
1. Unzip this archive. Keep everything in ONE folder — do not move files out of it.
2. Double-click index.html. It opens in your default web browser.

The folder must stay intact:

  index.html        the site (start here)
  support.js        page runtime
  image-slot.js     image display
  video-slot.js     video display
  images/           115 image files
  videos/           3 video files

Moving or renaming index.html is fine as long as it stays beside those files
and folders. Moving the images/ or videos/ folder will break the images.

NOTES
-----
• Works with no internet connection. Images and videos load from this folder.
• Fonts: the headline font (Abril Fatface) and body font (Work Sans) are loaded
  from Google Fonts. With a connection they look exactly like the live site;
  fully offline, the browser substitutes Georgia and Helvetica, so type looks
  slightly different but the layout is unchanged.
• Best viewed in Chrome, Edge, Safari, or Firefox.
• This is a snapshot for viewing and sharing. Dragging new images onto the page
  will not save here — add images in the editor, then export again.
